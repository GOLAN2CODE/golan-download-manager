# Windows Package Manager (winget)

Manifests for `Dark9guna.GolanDownloadManager`, validated with `winget validate`.
To publish a new version: copy the version folder into a fork of
[microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs) under the same path, update the version,
`InstallerUrl`, `InstallerSha256` and `ReleaseDate`, and open a pull request.

After it is merged, anyone can install Golan with:

```
winget install Dark9guna.GolanDownloadManager
```

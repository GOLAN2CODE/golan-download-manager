# Golan Download Manager — Store Listing (English)

## Name
Golan Download Manager

## Short Description (<= 132 characters)
Intercepts browser downloads for Golan Download Manager and captures web videos and batch links with one click.

## Detailed Description
Golan Download Manager is the official companion browser extension for the Golan Download Manager desktop application on Windows.

### Key Features
- **Automatic Download Interception**: Automatically hands off matching file downloads to the Golan desktop application for segmented, multi-connection acceleration and reliable pause/resume support.
- **Smart Video & Audio Panel**: Detects playable HTML5 media streams on web pages and offers a floating "Download this video" button so you can save videos and audio tracks directly in Golan.
- **Batch Link Capture**: Right-click any page and choose "Download all links with Golan" to filter and queue multiple files at once.
- **Per-Site Exceptions & Keyboard Shortcuts**: Configure exception sites in Golan, bypass interception temporarily with `Alt + Click`, or force capture with `Alt + Ctrl + Click`.
- **Full Bilingual Support**: Seamlessly supports both Arabic (RTL) and English (LTR) interfaces.

### System Requirements
This extension requires the **Golan Download Manager** desktop application to be installed on your Windows PC. The extension communicates exclusively with the local desktop app via the browser's standard Native Messaging channel (`com.golan.gdm`). When Golan is not running, your browser downloads continue normally through the browser's built-in download manager.
